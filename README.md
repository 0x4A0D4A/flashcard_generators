# flashcard_generators

A collection of programs for the programmatic generation of flashcards.

## Tools

| Tool | Description |
| --- | --- |
| [`wikt2card`](wikt2card/) | Fetch an English Wiktionary entry (definitions, IPA, etymology, examples, audio) and add it to Anki via AnkiConnect. |
